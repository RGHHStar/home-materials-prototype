# Changing material images

Every material detail page reads its image from this folder. To change a picture, replace the matching `.jpg` file while keeping the same filename.

Examples:

- `insulation-fibreglass.jpg`
- `flooring-bamboo.jpg`
- `lighting-standard-led.jpg`
- `solar-rooftop-solar-panels.jpg`

Recommended image format:

- JPEG (`.jpg`)
- Landscape orientation
- At least 1000 × 600 pixels
- Keep the file under about 1 MB when practical

The website does not need to be reprogrammed after an image is replaced. Refresh the page to see the new picture.

If an item image is missing, EverDwell automatically uses the representative image for that house system.
